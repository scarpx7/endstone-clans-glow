# Endstone Clans + Glow

Плагин для Endstone Bedrock (Python) — реализует систему кланов, подсветку (glow) для членов клана и возможность отключать PvP между участниками клана.

Установка:
1. Скопируйте папку `endstone-clans-glow` в `plugins/` вашего сервера Endstone.
2. Перезапустите сервер.
3. После первого запуска в папке плагина появится `data/` с `clans.json` и `config.json`.

Команды:
- /clans — список кланов
- /clan create <TAG> <Название> — создать клан
- /clan disband — распустить клан (лидер)
- /clan invite <Игрок> — пригласить
- /clan accept — принять приглашение
- /clan leave — выйти из клана
- /clan info [TAG|Игрок] — информация о клане
- /clan promote <Игрок> — назначить офицером (лидер)
- /clan demote <Игрок> — понизить
- /clan kick <Игрок> — выгнать
- /clan glow <on|off> — включить/выключить подсветку для клана
- /clan chat <on|off> — включить/выключить клан-чат
- /clan pvp <on|off> — включить/выключить PvP между членами клана (по умолчанию выключено)

Примечание:
- API Endstone может иметь отличия в именах методов. Если плагин не работает сразу, пришлите лог ошибок — я подправлю адаптеры (_get_online_player, _send, применение эффектов, имена событий).
